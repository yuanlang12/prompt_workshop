# 提示词模板来源说明

本项目的核心提示词模板来源如下，公开使用时请遵守对应来源的许可与条款。

## metaprompt.txt

生成提示词功能所用的 metaprompt 引自 **Anthropic 公开分享的 Metaprompt**（随 Anthropic
官方文档与控制台 Prompt Generator 发布的版本）。

- 原文版权归 Anthropic 所有，本仓库按原样引入用于生成功能
- 使用本项目时请同时遵守 Anthropic 的相关使用条款；如需在商业产品中分发该文本，
  请自行确认适用的许可

## improveprompt.txt / revise_plan_prompt.txt / remove_floating_variables.txt

提示词「优化 / 修订 / 变量规整」三个模板为本项目在 Anthropic Metaprompt 方法论
（结构化标签契约、变量抽取、思维链组织）基础上自行编写与迭代的结果，属于本项目
的一部分，随仓库以 MIT 许可分发。
